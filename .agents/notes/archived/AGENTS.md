# AGENTS.md — Archived Agent Notes

Archived pairs under the class directories are frozen historical snapshots, not current authority. Never edit, reformat, translate, repair, delete, or move a sealed artifact; use an active Agent Note or current documentation for new decisions and facts.

An archival change may only relocate a complete pair, insert the identical `Archived: YYYY-MM-DD` line below both `Status: implemented` lines, and repair or delete inbound links. Do not inspect, verify, or repair links out of archived notes; the classification and format gates skip them.
