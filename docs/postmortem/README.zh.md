# 复盘

[English](README.md) | 中文

openagent 的编号事故记录。复盘是唯一允许叙事的文档层级：它讲述到达用户或 CI 的缺陷的故事，确立根因，并转化为持久修复。

## 格式

文件名为 `NNNN-slug.md`，取下一个空闲编号，并配对 `NNNN-slug.zh.md`。每份复盘包含以下小节：

- **影响：** 谁观察到了什么，严重程度如何。
- **时间线：** 带时间戳的有序证据；记录事实而非教学序列。
- **根因：** 机制，而非近端失误。
- **行动项：** 每项转化为 issue、测试、验证门或 [Agent Note](../../.agents/notes/README.md)；没有落地跟进的复盘是不完整的。

## 规则

- 事故关闭时撰写复盘，而不是修复合入时；时间线是证据。
- 每个行动项链接其跟进；复盘本身保持为事故记录，不是任务跟踪器。
- 对人免责，对机制严格：命名允许缺陷存在的条件，而不是作者。
