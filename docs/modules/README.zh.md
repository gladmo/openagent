# 模块参考

[English](README.md) | 中文

openagent 中每个模块一页参考：类型、配置与语义。行为叙述归属[架构地图](../architecture.md)；决策依据归属 [Agent Note](../../.agents/notes/README.md)。

## 约定

- 每个模块一页，以模块命名；该页是模块的查阅范围，不是教程。
- 记录当前契约：带默认值与校验规则的配置字段、公开类型、不变量与失败行为。
- 局限与延期工作写入显式的 `## Known limitations` 小节；日常清理留在 TODO 标记。
- 当类型或表格存在权威来源（生成器、schema、导出清单）时，链接而不是复述。
- 页面创建的同一个提交里，把它登记进架构模块地图。
