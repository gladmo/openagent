# Cookbook

English | [中文](README.zh.md)

Step-by-step procedures for recurring changes in openagent. Each guide is a numbered path to one outcome; every guide ends with a verify step whose command actually exists. Design rationale does not live here — link the [Agent Note](../../.agents/notes/README.md) that owns the decision instead.

## Conventions

- One outcome per guide; the guide title names the outcome ("Adding a module", not "Modules").
- Number every step; a step that runs a command shows the command.
- End with a verify step: the exact check that proves the outcome, drawn from the real gate or test suite.
- State current behavior, never history; the slop checklist in the [documentation standard](../AGENTS.md) applies.
